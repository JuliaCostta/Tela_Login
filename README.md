# ➜] Tela de Login

## Visão Geral
Tela de Login criada em HTML 5 e CSS

## Algumas especificações
- Atributos como aria-describedby utilizado para melhorar acessibilidade do usuário;
- Possui configuração para mostrar ou ocultar a senha;
- Possui mensagens de erros quando os campos são preenchidos de maneira incorreta o quando não são preenchidos;
- Formulário centralizado e espaçamentos que preenchem toda a tela;
